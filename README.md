# MadLibs Project

### Description

This is a fun and interactive **Mad Libs Generator** built with Python! Mad Libs are word games where players fill in blanks with various parts of speech (like nouns, verbs, and adjectives) to create humorous and nonsensical stories. This project randomly selects a story template and prompts the user to enter words, then generates a final story based on the input.

Great for learning Python basics like string manipulation, user input, and file handling, or just to have a laugh!

### Features

- 🧠 Multiple Mad Libs story templates
- 👤 Interactive user input for words (nouns, verbs, adjectives, etc.)
- 😂 Hilarious and unexpected story outcomes
- 📂 Easy to add your own story templates
